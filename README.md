# 🏈 TouchDown

TouchDown is a modern iOS e-commerce application built using **SwiftUI**. The project focuses on creating a clean, engaging, and responsive shopping experience while exploring modern iOS development concepts such as reusable components, custom layouts, animations, and SwiftUI-based UI design.

This project was developed as part of my journey to strengthen my skills in **Swift, SwiftUI, and iOS application development**.

---

## 📱 About the Project

TouchDown is an iOS shopping application designed to provide users with an interactive product-browsing experience.

The application demonstrates how SwiftUI can be used to build modern mobile interfaces using reusable views, dynamic content, custom UI components, and smooth user interactions.

## 📂 Project Structure

The project follows a structured approach to keep different parts of the application organized.

```text
TouchDown
│
├── App
├── Models
├── Views
├── Components
├── Utilities
├── Resources
└── Assets
```

### Models

Contains the data models used throughout the application.

### Views

Contains the main SwiftUI screens displayed to the user.

### Components

Contains reusable SwiftUI components used across multiple screens.

### Assets

Contains images, icons, colors, and other visual resources used by the application.

## 🚀 Getting Started

### Requirements

To run this project, you will need:

- macOS
- Xcode
- iOS Simulator or a physical iOS device
- Git

---

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/DhruvPatel05/TouchDown.git
```

**2. Navigate to the project**

```bash
cd TouchDown
```

**3. Open the project in Xcode**

Open the `.xcodeproj` file using Xcode.

**4. Select a simulator**

Choose an available iPhone simulator or connect a physical iOS device.

**5. Build and run**

Press:

```text
⌘ + R
```

or click the **Run ▶** button in Xcode.
